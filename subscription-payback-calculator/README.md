# 订阅回本周期计算器

一个无需安装依赖、可直接在浏览器中打开的静态计算器。

## 支持参数

- 付费转化率 `c`
- 净收入率 `n`
- 月订阅用户占比 `q`，年订阅占比自动计算为 `1-q`
- 月订阅价格 `Pm`、年订阅价格 `Py`
- CPI / CAC
- 月订阅和年订阅的首次、第 2 次、第 3 次及后续续费率

## 计算口径

```text
R(t) = c × n × [qPmΣSm(k) + (1−q)PyΣSy(k)]
```

月订阅每月形成一次收费机会；年订阅在第 1、13、25……个月形成收费机会。年费按一次性现金收入计算，续费率按存活用户逐期相乘。

直接打开 `index.html` 即可使用。
